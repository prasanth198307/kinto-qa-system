Bugs Fixed (14 issues resolved)
DB Schema
patients — missing record_status, patient_code, allergies, notes
Routes querying WHERE record_status=1 crashed with "column does not exist". Several patient insert routes also referenced patient_code.
ALTER TABLE patients ADD COLUMN IF NOT EXISTS record_status INTEGER DEFAULT 1; ALTER TABLE patients ADD COLUMN IF NOT EXISTS patient_code TEXT;
DB Schema
wards — missing is_active, record_status
Ward listing route filtered on is_active which did not exist yet.
ALTER TABLE wards ADD COLUMN IF NOT EXISTS is_active INTEGER DEFAULT 1; ALTER TABLE wards ADD COLUMN IF NOT EXISTS record_status INTEGER DEFAULT 1;
DB Schema
appointments — 7 missing columns
appointment_no, doctor_name, specialization, slot_time, consultation_fee, notes, record_status all missing from the appointments table used by routes.
ALTER TABLE appointments ADD COLUMN IF NOT EXISTS appointment_no TEXT; ALTER TABLE appointments ADD COLUMN IF NOT EXISTS slot_time TEXT; ALTER TABLE appointments ADD COLUMN IF NOT EXISTS consultation_fee NUMERIC(10,2);
DB Schema
lab_tests — repurposed as ordered-test table (8 missing columns)
Routes use lab_tests for both catalog and ordered tests. patient_id, ordered_by, result, status etc. were all absent.
ALTER TABLE lab_tests ADD COLUMN IF NOT EXISTS patient_id TEXT; ALTER TABLE lab_tests ADD COLUMN IF NOT EXISTS status TEXT DEFAULT 'ordered';
DB Schema
prescriptions — missing prescription_code, notes, prescribed_at
ORDER BY pr.prescribed_at in GET /prescriptions failed; INSERT also referenced prescription_code.
ALTER TABLE prescriptions ADD COLUMN IF NOT EXISTS prescribed_at TIMESTAMPTZ DEFAULT NOW();
DB Schema
ipd_admissions — 5 missing columns
admission_no, doctor_name, treatment, daily_charge, record_status were absent from ipd_admissions.
ALTER TABLE ipd_admissions ADD COLUMN IF NOT EXISTS admission_no TEXT; ALTER TABLE ipd_admissions ADD COLUMN IF NOT EXISTS daily_charge NUMERIC(10,2) DEFAULT 0;

Added aliases: patient_name, patient_phone, appointment_time, fees const stime = slot_time || appointment_time || null; patient_id||null — prevents undefined in template

Tests send { medicines: [{name, dosage, duration}] } but route only accepted items with medicine_name key. Field name mismatch caused 500.
const rxItems = items || medicines || []; const mname = it.medicine_name || it.name || null;
Auth Fix
7 specialist users — role_id overrides users.role via COALESCE
Auth query: COALESCE(r.name, u.role). qa_hc_hr, qa_hc_sales, qa_hc_wh, qa_hc_prod, qa_hc_assets had role_id pointing to wrong role row — overriding the correct users.role column value.
UPDATE users SET role_id='qa-role-9200m', role='manager' WHERE username='qa_hc_hr' AND tenant_id=9200;
Plan Fix
production + warehouses blocked for healthcare_enterprise plan
plan-middleware.ts reads modules from subscription_plans DB table, not TypeScript constants. Must UPDATE the DB row directly.
UPDATE subscription_plans SET modules = modules || '["production","warehouses"]'::jsonb WHERE slug='healthcare_enterprise';
