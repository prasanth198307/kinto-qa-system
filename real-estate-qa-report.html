🔧 Bugs Fixed

SQL column mismatch — re_projects.name vs project_name
All GET/POST/PUT project routes used p.name but the schema column is project_name. Caused 500 errors on project list, unit join, and booking join. Fixed by aliasing all column references and accepting both name and project_name in request bodies.
server/realestate-routes.ts — POST/PUT /projects, GET /units, GET /bookings
Fixed
Type mismatch on broker JOIN — INTEGER vs VARCHAR
re_bookings.broker_id is INTEGER but re_brokers.id is VARCHAR. JOIN failed with PostgreSQL type mismatch error. Fixed with br.id::text = b.broker_id::text cast on both sides.
server/realestate-routes.ts — GET /bookings
Fixed
Missing re_demand_letters table
Routes referenced re_demand_letters which didn't exist in the schema. All demand letter endpoints threw 500. Created migration with full table DDL including booking_id, milestone, amount, paid_amount, and status columns.
db_scripts/2026-07-19_re-demand-letters-and-role-fixes.sql
Fixed
Missing /real-estate/customers API endpoint
No GET route existed for customer listing. Tests and frontend expected GET /api/real-estate/customers. Added a DISTINCT-on query that derives customers from re_bookings by customer_name and customer_phone.
server/realestate-routes.ts — new GET /customers
Fixed
role_id overrides users.role via COALESCE — 8 specialist users wrong
passport.js login uses COALESCE(r.name, u.role) — so even if users.role='manager', a stale role_id pointing to the operator row in the roles table wins. Fixed role_id for qa_re_hr, qa_re_wh, qa_re_prod, qa_re_assets, qa_re_sales, qa_re_site_engineer, qa_re_s_billing, qa_re_p_hr.
DB: UPDATE users SET role_id=... WHERE username IN (8 specialist users)
Fixed
production module missing from real_estate_enterprise plan (DB)
Plan enforcement middleware reads module lists from the subscription_plans DB table, not from plan-features.ts. The real_estate_enterprise row didn't include production or warehouses, blocking construction supervisors from production entries. Added both modules to the DB row and to plan-features.ts for consistency.
DB: UPDATE subscription_plans SET modules = modules || '["production","warehouses"]'
Fixed
POST /units — undefined field aliases caused SQL syntax error
Tests sent unit_number, floor, price but the route destructured unit_no, floor_no, base_price only. Undefined values interpolated as ${undefined} producing invalid SQL near commas. Fixed with dual-alias extraction for all field names.
server/realestate-routes.ts — POST /units
Fixed
Journal entries paginated response broke test .map()
GET /api/journal-entries returns {entries, total, page, pageSize}, not a plain array. Regional workflow tests called .json() as any[] then .map() — crashed with "map is not a function". Fixed with safe unwrap: Array.isArray(raw) ? raw : (raw.entries ?? []).
tests/functional/31b-real-estate-regional-workflows.test.ts
Fixed
Journal entries used group account codes (Cannot post to Group)
Tests posted to account codes 1000 (Assets group), 4000 (Income group), 2001 (Sundry Creditors group) — all non-ledger nodes. Changed to 1001 (Cash-in-Hand ledger) and 4001 (Sales Account ledger) which accept postings.
tests/functional/31-real-estate-role-workflows.test.ts, 31b-...
Fixed
Login rate limiter (429) during test runs
317 tests each call login(), generating 300+ login requests per run from 127.0.0.1. The rate limiter window (max 10 failures per 15 min) triggered midway. Fixed by launching the test server with DISABLE_LOGIN_RATE_LIMIT=true — the flag is already wired in security-middleware.ts.
server/security-middleware.ts — DISABLE_LOGIN_RATE_LIMIT env var
Fixed
POST /bookings failed when booking_date not sent
Route inserted ${booking_date} without a default. When tests omitted this field the template produced ${undefined} in SQL. Fixed with date fallback: booking_date || new Date().toISOString().split('T')[0].
server/realestate-routes.ts — POST /bookings
Fixed
Missing re_units columns referenced in routes
Routes and tests referenced current_price and features columns that didn't exist in re_units. Similarly re_bookings.total_amount was missing. Added all three via ALTER TABLE … ADD COLUMN IF NOT EXISTS in the migration.
