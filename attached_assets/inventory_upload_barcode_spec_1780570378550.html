Unknown barcode — 3 handling options
Option A
Quick-add inline
Mini form slides in — name, category, MRP, GST%. Item created in draft, GRN continues. Godown Incharge completes full details later.
Option B
Skip and flag
Item skipped, added to "unresolved barcodes" list. GRN submitted without it. Purchase Manager resolves later and raises amendment.
Option C
Block and notify
GRN cannot be submitted with unresolved items. Sends notification to Purchase Manager to add item master first. Strictest audit control.
Recommendation for SwachERP grocery: Use Option A for Godown Incharge (speed at gate), Option C for high-value items above ₹500 MRP (control). Configurable per item category in Terminal Settings.
