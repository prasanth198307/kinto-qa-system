1. Machine Startup Reminders

Overview

Machine Startup Reminders automatically send WhatsApp notifications to operators when machines need to be started and checklists completed.

Accessing Machine Startup Reminders

Navigation: Sidebar → Admin → Machine Startup Reminders

Reminder Configuration

FieldDescription
MachineSelect machine from master
Reminder TimeWhen to send reminder (e.g., 07:30 AM)
Checklist TemplateWhich checklist to complete
Assigned ToUser to receive reminder
WhatsApp NumberPhone number for notification
Days ActiveWhich days reminder is active
Is ActiveEnable/disable reminder

Creating a Reminder

1 Click "Add Reminder"
2 Select Machine and Checklist Template
3 Set reminder time (when to notify)
4 Assign user and enter WhatsApp number
5 Select active days (Mon-Sun)
6 Click "Save"

How It Works

  1. At scheduled time, system sends WhatsApp message
  2. Message includes machine name and checklist link
  3. Operator can complete checklist via WhatsApp
  4. Interactive Q&A session begins
  5. Responses recorded in system

3. Invoice Cancel & Reissue

Overview

Cancel & Reissue allows correcting invoices from the current month. The original invoice is cancelled and a new corrected invoice is created.

When to Use

  • Wrong customer selected
  • Incorrect product/quantity
  • Price errors
  • Wrong shipping address
Important: Cancel & Reissue is only available for current month invoices. For previous month invoices, use Credit Notes.

Cancel & Reissue Process

1 Open the invoice to be cancelled
2 Verify it's a current month invoice
3 Click "Cancel & Reissue" button
4 Confirm cancellation in dialog
5 New invoice form opens with pre-filled data
6 Make required corrections
7 Click "Save" to create new invoice

What Happens on Cancellation

ItemAction
Original InvoiceStatus changed to "Cancelled"
Stock ReservationReleased back to inventory
Gatepass (if any)Automatically cancelled
Payments (if any)Transferred to new invoice
Audit TrailLink maintained between old and new

5. Document Management System

Overview

Store and organize contracts, invoices, certificates, and other documents with versioning, category management, and sharing capabilities.

Accessing Documents

Navigation: Sidebar → Documents

Document Features

Uploading a Document

1 Click "Upload Document"
2 Select file from computer
3 Enter document details:

6. Vyapaar Data Import

Overview

Import data from Vyapaar accounting software via Excel files. Supports sale reports, payments, and vendor data with intelligent matching.

Accessing Data Import

Navigation: Sidebar → Admin → Data Import

Supported Imports

Import TypeSource FileDescription
Sale ReportSaleReport.xlsxInvoices with payment status
PaymentsPayments.xlsxPayment records with FIFO allocation
VendorsVendors.xlsxCustomer/supplier master data
ProductsProducts.xlsxProduct master data

Import Process

1 Select import type
2 Upload Excel file
3 System validates data:
  • Format checking
  • Required fields validation
  • Duplicate detection
4 Review validation results
5 Fuzzy matching for vendors/products:
  • System suggests matches
  • Confirm or correct mappings
6 Click "Import" to proceed
7 View import summary and errors

Intelligent Features

FeatureDescription
Fuzzy MatchingMatches similar vendor/product names
Date ConversionHandles various date formats
FIFO AllocationPayments auto-allocated to oldest invoices
De-duplicationPrevents duplicate imports
Error HandlingDetailed error reports

Payment Evidence System

Imported payments are linked as payment evidence:

  • Sale Report "Amount Received" = Immutable ledger
  • Payments.xlsx records = Payment evidence for audit

9. Common Scenarios

Scenario 1: Vyapaar Import with Fuzzy Matching

Situation: Importing sale report with vendor name variations

  1. Upload SaleReport.xlsx
  2. System validates data
  3. Fuzzy matching screen shows:
    Excel NameSuggested MatchConfidence
    "Sharma Traders Pvt""Sharma Traders Pvt Ltd"95%
    "ABC Industries""A.B.C. Industries Ltd"87%
    "Unknown Vendor XYZ"No match found-
  4. Review each suggestion
  5. Confirm correct matches
  6. For "Unknown Vendor XYZ":
    • Click "Create New" to add as new vendor
    • OR click "Skip" to exclude from import
  7. Proceed with import
  8. View import summary
Scenario 2: Handling Duplicate Detection

Situation: Re-importing file with some existing records

  1. Upload Payments.xlsx (contains 100 records)
  2. System detects 15 duplicates already in system
  3. Duplicate handling screen shows:
    • 85 new records to import
    • 15 duplicates found
  4. Options:
    • Skip duplicates: Import only 85 new records
    • Update duplicates: Overwrite existing with new data
    • Review each: Decide individually
  5. Select "Skip duplicates"
  6. Import proceeds with 85 records
  7. Summary shows what was imported vs skipped
Scenario 3: Document Expiry Alert Handling

Situation: FSSAI license expiring in 30 days

  1. System sends alert: "FSSAI License expires in 30 days"
  2. Admin receives email notification
  3. Go to Documents
  4. Find FSSAI License document
  5. Start renewal process externally
  6. Once renewed:
    • Click "Upload New Version"
    • Upload new license PDF
    • Enter new expiry date
    • Save
  7. Old version archived, new version active
  8. New expiry alert scheduled
Scenario 4: Linking Document to Vendor

Situation: Store vendor's GST certificate with their profile

  1. Go to Documents
  2. Click "Upload Document"
  3. Select GST Certificate PDF
  4. Title: "ABC Traders - GST Certificate"
  5. Category: "Vendor Documents"
  6. Link to Vendor: Select "ABC Traders"
  7. Expiry Date: Enter certificate validity
  8. Save
  9. Document now visible:
    • In Documents list
    • In Vendor Details → Documents tab
Scenario 5: Cancel & Reissue Current Month Invoice

Situation: Wrong customer selected on today's invoice

  1. Open the incorrect invoice
  2. Verify it's current month (Cancel & Reissue available)
  3. Click "Cancel & Reissue"
  4. Confirm cancellation warning
  5. New invoice form opens with pre-filled items
  6. Change customer to correct one
  7. Review all details
  8. Save new invoice
  9. Old invoice: Status = "Cancelled"
  10. New invoice: New number, correct customer
  11. Stock reservation transferred automatically

Scenario 7: Setting Up Machine Startup Reminder

Situation: New filling machine needs daily startup checklist

  1. Ensure machine exists in Machines master
  2. Ensure checklist template created
  3. Go to Admin → Machine Startup Reminders
  4. Click "Add Reminder"
  5. Configure:
    • Machine: "Filling Machine FM-03"
    • Checklist: "Filling Machine Startup"
    • Time: 7:30 AM
    • Assigned To: Ramesh (Operator)
    • WhatsApp: +91 98765 43210
    • Days: Monday to Saturday
  6. Save and activate
  7. Test by clicking "Send Test Message"
  8. Ramesh receives WhatsApp at 7:30 AM daily
Scenario 8: Viewing Cancelled Invoices Report

Situation: Auditor needs list of all cancelled invoices this quarter

  1. Go to Reports → Cancelled Invoices
  2. Set date range: Q3 (July-September)
  3. View list with:
    • Original invoice numbers
    • Cancellation dates
    • Cancelled by (user)
    • Reasons
    • Reissued as (if applicable)
  4. Click any row for full details
  5. Export to Excel for auditor
  6. Print summary report
