1. Introduction to Master Data

What is Master Data?

Master data is the core reference information that the entire system relies upon. It includes products you sell, raw materials you purchase, vendors you deal with, and configuration settings. Accurate master data ensures smooth operations across all modules.

Why Master Data is Important

Impact Area Why It Matters
Invoicing Products, HSN codes, and prices flow from master data
GST Compliance HSN codes and tax rates must be accurate
Inventory Stock is tracked against product/material masters
Production BOM defines material requirements for each product
Purchasing Vendor details used for purchase orders
Payments Vendor bank details for payment processing

Master Data Categories

Category Screens
Product Data Products, Product Categories, Product Types, BOM
Material Data Raw Materials, Raw Material Types, UOM
Vendor Data Vendors, Vendor Types
Configuration Invoice Templates, Bank Accounts, Terms & Conditions

2. Product Master

Overview

The Product Master contains all finished goods that you manufacture and sell. Each product has pricing, HSN codes, tax rates, and can have one or more Bill of Materials (BOM) configurations.

Accessing Product Master

Navigation: Sidebar → Inventory Management → Products Tab

Product List View

Column Description
Product Code Unique identifier (e.g., PRD-001)
Product Name Full name of the product
Category Product category classification
Type Product type within category
HSN Code GST classification code
Unit Price Standard selling price
GST Rate Applicable tax percentage
Status Active/Inactive

Creating a New Product

1 Click "Add Product" button
2 Fill in Basic Information:
  • Product Code: Unique identifier (auto-generated or manual)
  • Product Name: Full descriptive name
  • Description: Detailed description for invoices
3 Select Classification:
  • Category: Select from dropdown (e.g., Lubricants, Chemicals)
  • Type: Select type within category
4 Enter Tax Information:
  • HSN Code: 4-8 digit classification code
  • GST Rate: 0%, 5%, 12%, 18%, or 28%
5 Set Pricing:
  • Unit Price: Standard selling price per unit
  • MRP: Maximum retail price (if applicable)
6 Configure Units:
  • Primary UOM: Main unit of measure (e.g., Cases)
  • Secondary UOM: Alternate unit (e.g., Litres)
  • Conversion Factor: Units per case
7 Click "Save"

Product Fields Reference

Field Required Description
Product Code Yes Unique identifier, cannot be changed after creation
Product Name Yes Display name used in invoices and reports
Description No Detailed description for invoice line items
Category Yes Primary classification
Type No Sub-classification within category
HSN Code Yes Required for GST compliance
GST Rate Yes Tax rate applied on sales
Unit Price Yes Default selling price
Primary UOM Yes Main unit for inventory and invoicing
Pack Size No Number of units per pack/case
Is Active Yes Active products appear in dropdowns

Editing a Product

  1. Find product in list (use search)
  2. Click on product row or Edit icon
  3. Modify required fields
  4. Click "Save"
Warning: Changing HSN codes or GST rates affects future invoices only. Past invoices retain original values.

Deactivating a Product

Instead of deleting, deactivate products that are no longer sold:

  1. Edit the product
  2. Toggle "Active" to OFF
  3. Save

Deactivated products won't appear in invoice product selection but remain in historical records.

3. Raw Materials Master

Overview

Raw Materials are inputs used in manufacturing finished goods. They are tracked for inventory, linked to products via BOM, and used in purchase orders.

Accessing Raw Materials

Navigation: Sidebar → Inventory Management → Raw Materials Tab

Raw Material Fields

Field Required Description
Material Code Yes Unique identifier (e.g., RM-001)
Material Name Yes Descriptive name
Material Type Yes Classification (e.g., Base Oil, Additive)
Primary UOM Yes Main unit (e.g., Kg, Litre)
Secondary UOM No Alternate unit for conversion
Conversion Factor No Ratio between primary and secondary UOM
Reorder Level No Minimum stock before reordering
Loss Percentage No Expected wastage during production
HSN Code No For purchase orders and GST

Creating a Raw Material

1 Click "Add Raw Material"
2 Enter material details:
  • Material Code and Name
  • Select Material Type
  • Choose Primary UOM
3 Configure optional settings:
  • Secondary UOM and conversion factor
  • Reorder level for alerts
  • Expected loss percentage
4 Click "Save"

Inventory Modes

Raw materials support two inventory tracking modes:

Mode Use Case Behavior
Opening Stock Only Initial setup, migration Single opening balance entry
Ongoing Inventory Regular operations Purchase receipts increase, issuance decreases

4. Vendor Master

Overview

Vendors include customers (buyers) and suppliers. The same master is used for both, with vendor types distinguishing their role.

Accessing Vendor Master

Navigation: Sidebar → Admin → Vendor Management

Vendor Classification (Three-Tier System)

Tier Description Examples
Tier 1 - Distributors Large volume buyers with credit terms Regional distributors, Wholesalers
Tier 2 - Dealers Medium volume, mixed payment terms Local dealers, Retailers
Tier 3 - Retail/Institutional Direct customers, spot sales End consumers, Institutions

Vendor Fields

Field Required Description
Vendor Code Yes Unique identifier (auto or manual)
Vendor Name Yes Legal/registered name
Vendor Type(s) Yes Can have multiple types
GSTIN Conditional Required for GST-registered vendors
PAN No For TDS compliance
Address Yes Registered/billing address
City Yes City name
State Yes State (determines CGST/SGST vs IGST)
State Code Yes 2-digit GST state code
Pincode No Postal code
Contact Person No Primary contact name
Phone Yes Contact number
Email No For sending invoices
Credit Limit No Maximum outstanding allowed
Credit Days No Payment terms

Creating a Vendor

1 Click "Add Vendor"
2 Enter Basic Information:
  • Vendor Code (or let system generate)
  • Vendor Name (legal name as per GST)
  • Select Vendor Type(s)
3 Enter Tax Information:
  • GSTIN (15-digit GST number)
  • PAN (10-character)
4 Enter Address:
  • Complete billing address
  • City, State, State Code, Pincode
5 Enter Contact Details:
  • Contact person name
  • Phone number
  • Email address
6 Set Credit Terms (Optional):
  • Credit limit amount
  • Credit days (payment terms)
7 Add Shipping Address (Optional):
  • If delivery address differs from billing
  • Enter complete shipping details
8 Click "Save"

Multiple Vendor Types

A single vendor can have multiple types:

  • Example: "ABC Industries" can be both a Customer (you sell to them) and Supplier (they supply raw materials)
  • Set one type as "Primary" for revenue classification

Vendor History

View complete transaction history for any vendor:

  1. Open vendor details
  2. Click "View History" or navigate to Vendor History screen
  3. See all invoices, payments, credit notes, and outstanding

10. Bill of Materials (BOM)

Overview

BOM defines the recipe for manufacturing a product. It specifies which raw materials are needed and in what quantities.

Accessing BOM

Navigation: Sidebar → Inventory Management → Products → Click Product → BOM Tab

BOM Structure

Field Description
BOM Name Identifier for this recipe (e.g., "Standard", "Economy")
Product Finished good this BOM produces
Output Quantity Amount produced by this recipe
Output UOM Unit of output (e.g., Cases, Litres)
Is Default Default BOM used when issuing materials
Is Active Active BOMs available for production

BOM Items (Ingredients)

Field Description
Raw Material Input material from Raw Materials master
Quantity Amount needed per output unit
UOM Unit of measure for input
Loss % Expected wastage percentage

Multi-BOM Configuration

A product can have multiple BOMs for different scenarios:

  • Standard BOM: Normal production recipe
  • Economy BOM: Cost-effective alternative ingredients
  • Premium BOM: Higher quality ingredients
Important: When issuing raw materials for production, you must explicitly select which BOM to use. The system does not auto-select.

Creating a BOM

  1. Navigate to Product detail page
  2. Click "BOM" tab
  3. Click "Add BOM"
  4. Enter BOM name and output details
  5. Add raw material items:
    • Select raw material
    • Enter quantity
    • Set loss percentage if applicable
  6. Mark as default if primary recipe
  7. Click "Save"

13. Best Practices

Data Entry Guidelines

Product Codes:
  • Use consistent format (e.g., PRD-001, PRD-002)
  • Include category prefix if helpful (e.g., LUB-001 for Lubricants)
  • Avoid special characters
HSN Codes:
  • Verify codes from official GST portal
  • Use 6-8 digit codes for accuracy
  • Review periodically for updates
Vendor GSTIN:
  • Validate format: 2 digit state + 10 char PAN + 3 chars
  • Verify on GST portal before entry
  • State code must match GSTIN first 2 digits

Maintenance Checklist

Task Frequency
Review and update product prices Monthly or as needed
Verify vendor GSTIN status Quarterly
Check BOM accuracy After any formula change
Deactivate obsolete products As needed
Update reorder levels Quarterly
Review credit limits Annually or on request

Common Mistakes to Avoid

  • ❌ Creating duplicate vendors (search first!)
  • ❌ Wrong HSN codes (verify on GST portal)
  • ❌ Incorrect state codes (causes wrong GST type)
  • ❌ Missing BOM items (production variance)
  • ❌ Deleting instead of deactivating
  • ❌ Wrong UOM conversions
