How to create a new plan (Super Admin)

  1. Go to Super Admin → Plans (super-admin-plans.tsx)
  2. Click Create Plan → set name, slug, price_monthly, price_yearly in paise
  3. Select modules from MODULE_NAV_ITEMS keys (e.g. restaurant, hr_payroll)
  4. Set max_users, trial_days, features[ ] (human-readable bullets)
  5. Save → appears on /pricing page for new tenants
  6. Existing tenant upgrade: Super Admin → Tenants → change plan_slug

How to set permissions for a role (UI flow)

  1. Go to Users → Role & Permissions (role-permissions screen)
  2. Select role from dropdown (e.g. "Hotel Manager")
  3. Grid shows all screens with 4 checkboxes: View / Create / Edit / Delete
  4. Check/uncheck → saved to role_permissions table
  5. Change takes effect immediately (no cache for permissions)
Auto-grant on new screen: When a new screen_key is added to nav-screen-map.ts, the server auto-patches role_permissions on startup — granting can_view=1 to all admin roles across all tenants. No SQL migration needed for new screens. Non-admin roles start with can_view=0 until an admin explicitly grants access.
