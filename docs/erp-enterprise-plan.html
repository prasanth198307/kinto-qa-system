Two-layer access control: Layer 1 = Plan gates — which modules (nav sections) are visible based on subscription. Layer 2 = Role gates — within each visible screen, what CRUD actions can this role perform. Both must pass. A screen hidden by plan cannot be accessed even if role permits it.

How to create a new plan (Super Admin)

  1. Go to Super Admin → Plans (super-admin-plans.tsx)
  2. Click Create Plan → set name, slug, price_monthly, price_yearly in paise
  3. Select modules from MODULE_NAV_ITEMS keys (e.g. restaurant, hr_payroll)
  4. Set max_users, trial_days, features[ ] (human-readable bullets)
  5. Save → appears on /pricing page for new tenants
  6. Existing tenant upgrade: Super Admin → Tenants → change plan_slug

How to set permissions for a role (UI flow)

  1. Go to Users → Role & Permissions (role-permissions screen)
  2. Select role from dropdown (e.g. "Hotel Manager")
  3. Grid shows all screens with 4 checkboxes: View / Create / Edit / Delete
  4. Check/uncheck → saved to role_permissions table
  5. Change takes effect immediately (no cache for permissions)
Auto-grant on new screen: When a new screen_key is added to nav-screen-map.ts, the server auto-patches role_permissions on startup — granting can_view=1 to all admin roles across all tenants. No SQL migration needed for new screens. Non-admin roles start with can_view=0 until an admin explicitly grants access.

Foundation (do first — unlocks all ERPs)

1
PostgreSQL Row Level Security2 wks
ALTER TABLE … ENABLE ROW LEVEL SECURITY. Policy: tenant_id = current_setting('app.tenant_id'). One migration, fixes multi-tenant data isolation for all 17 ERPs. Enterprise prerequisite.
2
PDF Engine — server/pdf-service.ts2 wks
Puppeteer + Handlebars. One service, all ERPs call POST /api/pdf/generate with template name + data. Unlocks: 80G certs, passbooks, folios, LRs, fee receipts, IPD bills, demand letters.
3
GL Auto-posting: all verticals → journal-service.ts3 wks
Import journalService.post() in Restaurant, Hotel, Healthcare, Pharmacy, Nidhi, NGO, Education, Retail, Logistics routes. Finance ERP then shows real cross-ERP consolidated P&L.
4
Notification engine — server/notif-service.ts1 wk
One WhatsApp/SMS service. Nidhi EMI alerts, Education fee reminders, Healthcare appointment pings, Hotel check-in, Restaurant order status — all call same notifService.send().
