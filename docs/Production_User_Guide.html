2. Raw Material Issuance

Overview

Raw Material Issuance transfers materials from inventory to production floor. It is BOM-driven and supports multiple BOMs per product.

Accessing Issuance

Navigation: Dashboard → Raw Material Issuance Tab OR Sidebar → Production Management

Creating an Issuance

1 Click "New Issuance"
2 Set Issuance Details:
  • Date (default: today)
  • Issued To (free text - operator name or department)
3 Select Product:
  • Choose the finished product being manufactured
  • Product must have at least one active BOM
4 Select BOM:
  • Dropdown shows all active BOMs for the product
  • You must explicitly select - no auto-selection
  • Different BOMs may use different ingredients
Important: BOM selection is mandatory and explicit. The system will not auto-select a default BOM. You must consciously choose which recipe to use.
5 Enter Production Quantity:
  • How many units are you planning to produce?
  • System calculates required materials based on BOM
6 Review Material Requirements:
  • System shows required quantities per BOM
  • Green = sufficient stock available
  • Red = insufficient stock
7 FIFO Batch Allocation:
  • Materials are allocated from oldest batches first
  • View batch breakdown for each material
  • System may use multiple batches to fulfill requirement
8 Click "Issue Materials"

3. Production Entry

Overview

Production Entry records finished goods manufactured from issued raw materials.

Creating Production Entry

1 Navigate to Production Management
2 Click "Record Production"
3 Link to Issuance (optional):
  • Select related issuance for variance tracking
  • Or record standalone production
4 Enter Production Details:
  • Product manufactured
  • Quantity produced
  • Batch number (for traceability)
  • Production date
5 Quality Status:
  • Pending QC (default)
  • QC Passed
  • QC Failed
6 Click "Save Production"

Variance Analysis

When linked to an issuance, system calculates variance:

MetricFormula
Expected OutputIssuance Planned Quantity
Actual OutputProduction Entry Quantity
VarianceActual - Expected
Variance %(Variance / Expected) x 100

4. Production Reconciliation

Overview

End-of-day reconciliation matches issued materials against actual consumption. It identifies variances and helps control wastage.

Accessing Reconciliation

Navigation: Sidebar → Reports → Production Reconciliation

Reconciliation Process

1 Select Date (or date range)
2 Review Summary:
  • Total materials issued
  • Total production recorded
  • Expected consumption vs. actual
3 For each material, enter:
  • Actual consumption (if different from calculated)
  • Reason for variance (if any)
4 Submit Reconciliation

Reconciliation Fields

FieldDescription
DateReconciliation date
MaterialRaw material name
OpeningStock at start of day
IssuedMaterials issued during day
Consumed (Calculated)Based on production entries
Consumed (Actual)Physical count / adjustment
ClosingStock at end of day
VarianceDifference requiring explanation

6. Finished Goods Approval

Overview

Finished goods require quality approval before they can be sold. This ensures only quality-checked products are invoiced.

Accessing Finished Goods

Navigation: Sidebar → Inventory Management → Finished Goods Tab

Approval Workflow

Production Entry → Pending QC → Quality Check → Approved/Rejected → Available for Sale

Approving Finished Goods

1 Go to Finished Goods tab
2 Filter by "Pending Approval" status
3 Select batch(es) to approve
4 Click "Approve" or "Reject"
5 If rejecting, enter reason

Stock Visibility

StatusAvailable for Invoice?Shown in Stock?
Pending QCNoYes (as pending)
ApprovedYesYes (as available)
RejectedNoYes (as rejected)

Consolidated View

The Finished Goods tab includes a "Consolidated" toggle:

  • Detailed View: Shows each inventory record separately
  • Consolidated View: Groups by product and batch number
  • Shows source breakdown: Production / Restock / Repack
  • Expandable to see individual records

7. Common Scenarios

Scenario 1: Standard Production Run

Situation: Produce 100 cases of Engine Oil 5W-30

  1. Create new Raw Material Issuance
  2. Select product: "Engine Oil 5W-30"
  3. Select BOM: "Standard Formula"
  4. Enter quantity: 100 cases
  5. Review material requirements (base oil, additives, etc.)
  6. Confirm FIFO batch allocation
  7. Issue materials - inventory decreases
  8. After manufacturing, record production entry
  9. Enter batch number for traceability
  10. Quality team approves finished goods
  11. 100 cases now available for sale
Scenario 2: Using Economy BOM

Situation: Cost reduction needed - use alternate formula

  1. Create issuance
  2. Select product
  3. From BOM dropdown, select "Economy Formula"
  4. Note: Different materials may be required
  5. Proceed with issuance and production
  6. Mark finished goods with formula identifier
Scenario 3: Production Variance Investigation

Situation: Produced 95 cases instead of expected 100

  1. Check reconciliation report
  2. Identify variance: -5 cases (5%)
  3. Investigate causes:
    • Weighing accuracy?
    • Material quality issues?
    • Equipment problems?
    • Operator error?
  4. Document findings in variance remarks
  5. If BOM is inaccurate, update loss percentage
Scenario 4: Multi-Batch Material Issuance

Situation: Need 500 Kg base oil, but spread across batches

  1. Create issuance as normal
  2. System shows FIFO allocation:
    • Batch A (oldest): 200 Kg
    • Batch B: 300 Kg
  3. Review allocation before confirming
  4. Issue materials - both batches depleted accordingly
  5. Issuance shows batch breakdown for records
Scenario 5: Quality Rejection

Situation: QC finds defects in produced batch

  1. Go to Finished Goods
  2. Find the batch in "Pending QC"
  3. Click "Reject"
  4. Enter reason: "Viscosity out of spec"
  5. Batch marked as rejected
  6. Not available for invoicing
  7. Investigate and decide: rework or scrap
