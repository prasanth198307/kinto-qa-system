1. Machine Management

Overview

Machine Management maintains a registry of all production and utility equipment. Machines are linked to spare parts, checklists, and maintenance plans.

Accessing Machines

Navigation: Sidebar → Admin → Machines

Machine Fields

FieldRequiredDescription
Machine CodeYesUnique identifier (e.g., M-001)
Machine NameYesDescriptive name
Machine TypeYesClassification (e.g., Filling, Mixing)
LocationNoPhysical location in plant
ManufacturerNoEquipment manufacturer
Model NumberNoManufacturer model
Serial NumberNoEquipment serial number
Installation DateNoWhen installed
StatusYesActive/Inactive/Under Maintenance

Creating a Machine

1 Click "Add Machine"
2 Enter machine details:
  • Code and Name
  • Select Machine Type
  • Enter location and specifications
3 Click "Save"

Machine Types

Configure machine types in Admin → Machine Types:

  • Filling Machine
  • Mixing Tank
  • Packaging Line
  • Compressor
  • Boiler
  • Generator

2. Spare Parts Management

Overview

Spare Parts Catalog manages the master list of spare parts and consumables. It links parts to specific machines.

Accessing Spare Parts

Navigation: Sidebar → Admin → Spare Parts

Spare Part Fields

Creating a Spare Part

1 Click "Add Spare Part"
2 Enter part details:
  • Part code and name
  • Select associated machine (optional)

3. Spare Parts Stock

Overview

Spare Parts Stock tracks inventory of spare parts with entries (purchases), issuances (stock-out), and returns.

Accessing Spare Parts Stock

Navigation: Sidebar → Spare Parts Stock

Stock Entry (Purchase)

1 Click "Add Entry"
2 Select Spare Part
3 Enter Details:
  • Quantity received
  • Unit price
  • GST rate
  • Vendor/Supplier
  • Invoice reference
4 Click "Save Entry"

Stock Issuance

1 Click "Issue Spare Part"
2 Select Spare Part:
  • If part has assigned machine, it pre-populates
3 Enter Details:
  • Quantity issued
  • Machine (if applicable)
  • Issued To (free text - person/department)
  • Reason for issuance
4 Click "Issue"

Stock Return

Return unused parts back to stock:

  1. Click "Return"
  2. Select original issuance
  3. Enter return quantity
  4. Enter return reason
  5. Confirm return

Stock Tracking

ColumnDescription
Opening StockBeginning balance
EntriesPurchases/receipts
IssuancesStock issued out
ReturnsStock returned
Current StockAvailable balance

4. Checklists

Overview

Checklists ensure systematic verification of equipment and processes. They can be completed via the app or WhatsApp.

Checklist Components

1. Checklist Templates

Navigation: Sidebar → Admin → Checklist Templates

Templates define the checklist structure:

  • Template name and description
  • Associated machine (optional)
  • Questions/items to check
  • Answer types (Yes/No, Numeric, Text, Photo)

2. Checklist Assignments

Navigation: Sidebar → Admin → Checklist Assignments

Assignments schedule checklists:

  • Which template
  • Which machine/area
  • Assigned user
  • Frequency (Daily, Weekly, Monthly)
  • Due time

3. Checklist Completion

Navigation: Sidebar → Checklists

View and complete pending checklists:

  • List of assigned checklists
  • Status: Pending, In Progress, Completed
  • Click to open and complete

Completing a Checklist

1 Open pending checklist
2 Answer each question:
  • Yes/No for verification items
  • Numeric values for readings
  • Text for observations
  • Photo upload for evidence
3 Add remarks if needed
4 Submit checklist

5. Preventive Maintenance

Overview

Preventive Maintenance (PM) schedules and tracks routine maintenance tasks to prevent equipment failures.

PM Components

1. PM Task Templates

Navigation: Sidebar → Admin → PM Templates

Define standard maintenance tasks:

  • Task name and description
  • Associated machine type
  • Estimated duration
  • Required spare parts
  • Step-by-step instructions

2. Maintenance Plans

Navigation: Sidebar → Admin → Maintenance Plans

Schedule PM activities:

  • Select machine
  • Select PM template
  • Set frequency (Weekly, Monthly, Quarterly)
  • Set next due date
  • Assign technician

3. PM Execution

Navigation: Sidebar → PM Execution

Execute scheduled maintenance:

  • View upcoming and overdue tasks
  • Start maintenance
  • Record observations
  • Record parts used
  • Mark complete

PM Workflow

Plan Created → Task Generated → Assigned → In Progress → Completed → Next Schedule

PM Execution Steps

1 Open pending PM task
2 Click "Start" - records start time
3 Follow checklist items
4 Record spare parts used:
  • Select spare part
  • Enter quantity used
  • Stock automatically deducted
5 Add observations/findings
6 Click "Complete" - records end time

PM History

Navigation: Sidebar → Reports → PM History

View maintenance history:

  • All completed PM tasks
  • By machine or date range
  • Duration and costs
  • Parts consumed

6. WhatsApp Integration

Overview

Complete checklists via WhatsApp for operators without app access. AI-assisted response interpretation.

Machine Startup Reminders

Navigation: Sidebar → Admin → Machine Startup Reminders

Configure automatic reminders:

  • Select machine
  • Set reminder time
  • Assign WhatsApp number
  • Link checklist template

WhatsApp Checklist Flow

  1. System sends reminder at scheduled time
  2. Operator receives WhatsApp message
  3. Interactive Q&A begins
  4. Operator responds to each question
  5. AI interprets responses (yes/no variants)
  6. Photos can be sent as attachments
  7. Responses saved to database
  8. Checklist marked complete

Answer Types via WhatsApp

TypeExpected Response
Yes/No"yes", "y", "haan", "ok" / "no", "n", "nahi"
NumericNumber value (e.g., "45", "120.5")
TextAny text response
PhotoImage attachment

Missed Checklist Notifications

If checklist not completed by due time:

  • System sends reminder notification
  • Supervisor alerted via email/WhatsApp
  • Overdue status shown in dashboard

7. Common Scenarios

Scenario 1: Setting Up a New Machine
  1. Go to Machines, create new machine record
  2. Go to Spare Parts, add spare parts for this machine
  3. Create checklist template for daily inspection
  4. Create PM template for monthly service
  5. Create maintenance plan with schedule
  6. Machine now tracked for all activities
Scenario 2: Daily Machine Startup
  1. Operator receives WhatsApp reminder at 8:00 AM
  2. Answers startup checklist questions via WhatsApp
  3. Sends photo of gauge reading
  4. Checklist completed and recorded
  5. Supervisor sees green status in dashboard
Scenario 3: Using Spare Part During Repair
  1. Machine breakdown occurs
  2. Technician identifies failed part
  3. Go to Spare Parts Stock
  4. Issue the required spare part
  5. Select machine, enter "Issued To"
  6. Stock decremented
  7. Record maintained for tracking
Scenario 4: Monthly Preventive Maintenance
  1. System generates PM task based on plan
  2. Technician sees task in PM Execution
  3. Clicks "Start" to begin
  4. Follows PM checklist
  5. Replaces filter and records part usage
  6. Adds observation: "Belt showing wear"
  7. Marks complete
  8. Next PM scheduled automatically
Scenario 5: Ordering Low-Stock Spare Parts
  1. Spare part reaches reorder level
  2. Alert shown in dashboard
  3. Create purchase requisition
  4. When parts received, create stock entry
  5. Enter quantity, price, vendor
  6. Stock level restored
Scenario 6: Emergency Spare Part Issuance

Situation: Filling machine breaks down, needs immediate belt replacement

  1. Production calls for urgent spare
  2. Go to Spare Parts Stock
  3. Click "Issue Spare Part"
  4. Select: "Conveyor Belt - FM-01"
  5. Machine auto-populates (if linked)
  6. Quantity: 1
  7. Issued To: "Raju - Maintenance Tech"
  8. Reason: "Emergency breakdown repair"
  9. Priority: Mark as "Urgent"
  10. Issue immediately
  11. Stock decremented
  12. If below reorder level, alert triggered
Scenario 7: Return of Unused Spare Parts

Situation: Technician issued 3 bearings, used only 2

  1. Go to Spare Parts Stock
  2. Find original issuance record
  3. Click "Return"
  4. Enter return quantity: 1
  5. Condition: Good (unused)
  6. Reason: "Not required for repair"
  7. Confirm return
  8. Stock increased by 1
  9. Original issuance updated: 3 issued, 1 returned, net 2 used
Scenario 8: WhatsApp Checklist with Photo

Situation: Operator completes startup checklist via WhatsApp

  1. 7:30 AM - System sends WhatsApp reminder
  2. Message: "Good morning! Time for FM-01 startup checklist"
  3. Q1: "Is oil level okay?" → Operator replies "yes"
  4. AI interprets as YES ✓
  5. Q2: "Temperature reading?" → Operator replies "45"
  6. Recorded as numeric: 45 ✓
  7. Q3: "Send photo of gauge" → Operator sends image
  8. Photo downloaded and stored ✓
  9. Q4: "Any unusual noise?" → Operator replies "nahi"
  10. AI interprets Hindi "nahi" as NO ✓
  11. Checklist completed and saved
  12. Dashboard shows green status
Scenario 9: Missed Checklist Escalation

Situation: Operator doesn't complete checklist by due time

  1. 8:00 AM - Checklist due time
  2. 8:00 AM - System sends first reminder to operator
  3. 8:15 AM - Still not completed
  4. 8:15 AM - Second reminder + supervisor notified
  5. Supervisor receives WhatsApp: "FM-01 checklist overdue"
  6. 8:30 AM - Still pending
  7. Manager receives email escalation
  8. Dashboard shows RED status for FM-01
  9. Supervisor contacts operator
  10. Checklist completed at 8:45 AM (late)
  11. Recorded with "Late completion" flag
Scenario 10: PM with Multiple Spare Parts

Situation: Quarterly service requires multiple parts

  1. PM task generated: "Quarterly Service - Compressor"
  2. Technician starts PM task
  3. Follows checklist:
    • Check oil → OK
    • Check filter → Needs replacement
    • Check belt → Needs replacement
    • Check gasket → OK
  4. Record spare parts used:
    • Air Filter x1 - ₹450
    • V-Belt x1 - ₹280
  5. Stock auto-deducted for both
  6. Add observation: "Minor rust on housing"
  7. Complete PM task
  8. Total parts cost: ₹730 recorded
  9. Next PM scheduled for 3 months
Scenario 11: Machine Breakdown Logging

Situation: Filling machine stops working unexpectedly

  1. Operator reports breakdown
  2. Go to Machines → Select FM-01
  3. Click "Log Breakdown"
  4. Enter details:
    FieldValue
    Start Time10:30 AM

    Production LossYes
  5. Assign to technician
  6. Technician repairs machine
  7. Update: End Time = 12:15 PM
  8. Total downtime: 1 hr 45 min logged
  9. Spare parts used recorded
Scenario 12: Calibration Due Alert

Situation: Weighing scale calibration expiring in 7 days

  1. Dashboard shows alert: "Calibration Due"
  2. Go to Machines → Weighing Scale WS-01
  3. View calibration history
  4. Schedule external calibration agency visit
  5. After calibration:
    • Go to machine record
    • Click "Record Calibration"
    • Enter calibration date
    • Enter next due date
    • Attach calibration certificate
  6. Alert cleared
  7. New alert scheduled for next due date
Scenario 13: Finished Goods Quality Approval

Situation: New production batch needs QC approval

  1. Production completes batch of 100 cases
  2. Batch appears in Finished Goods → Pending QC
  3. QC takes samples for testing
  4. Run tests:
    • Viscosity: ✓ Pass
    • Flash Point: ✓ Pass
    • Appearance: ✓ Clear
    • Specific Gravity: ✓ Within range
  5. Open batch in system
  6. Click "Approve for Sale"
  7. Enter test results/certificate number
  8. Batch status: "Approved"
  9. Available for invoicing
Scenario 14: Non-Conformance Recording

Situation: Customer complaint about product quality

  1. Go to Quality → Non-Conformances
  2. Click "New NCR"
  3. Enter details:
    • Type: Customer Complaint
    • Product: Gear Oil 20L
    • Batch: B-2024-0125
    • Description: "Oil appears cloudy"
    • Customer: ABC Industries
  4. Assign to QC Manager
  5. Investigation:
    • Check retained sample
    • Review production records
    • Check storage conditions
  6. Root cause: Water contamination during filling
  7. Corrective action: Seal inspection procedure added
  8. Close NCR with findings
Scenario 15: Spare Parts Stock Take

Situation: Monthly spare parts inventory count

  1. Go to Spare Parts Stock
  2. Print current stock list
  3. Physical count all items:
    ItemSystemPhysicalVariance
    V-Belt A6812120
    Bearing 620587-1
    Oil Seal 25x4015150
    Filter Element65-1
  4. For variances, create adjustments
  5. Investigate missing items
  6. Update stock accordingly
  7. Document count results
Scenario 16: PM Schedule Creation

Situation: Setting up PM plan for new machine

  1. Ensure machine exists in Machines master
  2. Go to Preventive Maintenance → Plans
  3. Click "Create Plan"
  4. Configure:
    • Machine: Compressor CP-01
    • PM Type: Routine Service
    • Frequency: Monthly
    • Checklist: Select "Compressor Monthly"
    • Assigned To: Maintenance Team
    • Estimated Duration: 2 hours
  5. Expected parts (auto-order):
    • Air Filter x1
    • Oil (if due)
  6. Save plan
  7. First PM task generated automatically
  8. Recurring tasks created per schedule
