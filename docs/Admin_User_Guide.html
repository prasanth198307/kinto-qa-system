1. User Management

Overview

User Management controls who can access the system and what they can do.

Accessing Users

Navigation: Sidebar → Admin → Users

User Fields

FieldRequiredDescription
UsernameYesUnique login name
EmailYesFor notifications and login
Full NameYesDisplay name
PasswordYesSecure password
RoleYesAssigned role(s)
PhoneNoContact number
WhatsAppNoFor WhatsApp integration
StatusYesActive/Inactive

Creating a User

1 Click "Add User"
2 Enter User Details:
  • Username (unique, no spaces)
  • Email address
  • Full name
  • Phone number
3 Set Password:
  • Strong password required
  • Minimum 8 characters
4 Assign Role(s):
  • Select one or more roles
  • Roles determine permissions
5 Click "Save"

Editing a User

  1. Find user in list
  2. Click Edit icon
  3. Modify required fields
  4. Save changes

Deactivating a User

  1. Edit the user
  2. Toggle Status to "Inactive"
  3. Save
Note: Deactivated users cannot log in but their data and audit trail are preserved.

Password Reset

  1. Edit the user
  2. Click "Reset Password"
  3. Enter new password
  4. Save

3. Permissions

Overview

Permissions control access to specific screens and actions. They are assigned to roles, not directly to users.

Permission Structure

Each screen has multiple permission levels:

LevelAllows
ViewSee the screen and data
CreateAdd new records
EditModify existing records
DeleteRemove records
ApproveApprove/reject items
ExportExport data

  • write_off_report - Write-off access

Quality & Maintenance

Configuring Role Permissions

1 Open Role → Permissions Tab
2 For each screen:
  • Check permissions to grant
  • Uncheck to deny
3 Use "Select All" for quick setup
4 Click "Save Permissions"

5. Audit & Security

Audit Trail

System maintains audit trail for:

  • User logins/logouts
  • Record creation
  • Record modifications
  • Record deletions
  • Permission changes
  • Critical actions

Viewing Audit Logs

Navigation: Sidebar → Admin → Audit Logs

ColumnDescription
TimestampWhen action occurred
UserWho performed action
ActionWhat was done
EntityWhat was affected
DetailsAdditional information

Security Best Practices

Recommended:
  • Use strong, unique passwords
  • Assign minimum required permissions
  • Regularly review user access
  • Deactivate unused accounts
  • Review audit logs periodically
  • Keep role definitions updated
Avoid:
  • Sharing login credentials
  • Giving admin access unnecessarily
  • Using weak passwords
  • Leaving inactive users active
