Bugs Fixed This QA Cycle

CRITICAL
Server crashes on unmatched API routes
server/index.ts:295–298
Without NODE_ENV=production, Express loads Vite dev middleware. Any unmatched route hit the SPA fallback which tried to transform /src/main.tsx from non-existent source files, throwing an unhandled rejection that crashed the entire server process mid-test run.
Fix: Always run NODE_ENV=production PORT=5050 node dist/index.js. Systemd unit file must carry Environment=NODE_ENV=production. Root cause in if (env === "development") setupVite() branch.
HIGH
Sketch POST — wrong SQL column names
server/gold-erp-routes2.ts · INSERT jw_sketch_process
Handler referenced columns sketch_image_url, design_category, stone_details, and status — none of which exist in jw_sketch_process. Every POST returned HTTP 500 with a PostgreSQL "column does not exist" error.
Fix: INSERT uses only real columns: (tenant_id, production_order_id, design_id, customer_brief). All optional fields wrapped with || null to avoid Drizzle undefined-in-template bugs.
HIGH
Chit-schemes POST — boolean passed to INTEGER column
server/gold-erp-routes.ts · /chit-schemes
Test sends bonus_month_free: true (JSON boolean). PostgreSQL rejected it with "column is of type integer but expression is of type boolean". Scheme creation always returned 500.
Fix: Ternary cast ${bonus_month_free ? 1 : 0} in the Drizzle sql template. Boolean from JSON body is now safely coerced to INTEGER 0/1.
HIGH
Branches POST — wrong column names + NOT NULL violation
server/masters-routes.ts · POST /api/masters/branches
Handler inserted into non-existent name column. Real table schema requires branch_code (NOT NULL, UNIQUE) and branch_name (NOT NULL). Additionally, optional fields like gstin passed as undefined generating invalid SQL via Drizzle's template literal.
Fix: Auto-generate branch_code = 'BR-' + Date.now().slice(-8). Use correct column names branch_code, branch_name. Wrap all optional fields with || null. PUT handler updated similarly (SET branch_name=…).
MEDIUM
Chit member enrollment — field name mismatch
server/gold-erp-routes.ts · /chit-schemes/:id/members
Test sends customer_name and customer_phone (CRM-style naming), but handler expected member_name and phone. Enrollment returned 500 with NULL constraint violation on the name column.
Fix: Handler now accepts both aliases: const name = member_name || customer_name and const tel = phone || customer_phone. Backward-compatible — existing clients using old field names continue to work.
